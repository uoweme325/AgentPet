# AgentPet v1.4.1 · 智能桌宠助手

多 Agent 智能协同桌面宠物挂件，支持 **Antigravity**（反重力）、**Codex** 与 **DeepSeek Harness**（DSH）工作状态联动与额度实时监控。

## 📝 v1.4.1 更新日志
- **小型视觉与拖动修正**：
  - 托盘桌宠图标先按透明像素裁切，再缩放到统一 32px，修正角色图标大小不齐。
  - 桌宠拖动边界按当前显示器工作区和角色本体尺寸计算，角色最多移出屏幕一半，气泡区域不参与限制。
  - 支持负坐标副屏、不同分辨率和 DPI，不使用本机固定屏幕尺寸。

## 📝 v1.4.0 更新日志
  - **托盘体验优化**：
  - 托盘图标随 Claude、Dragon、Gemini 桌宠立绘切换，不使用 Agent 图标，避免与 Antigravity/Codex/DSH 混淆。
  - 菜单动态显示当前角色、桌宠显示状态、气泡面板和播报暂停状态。
  - 新增托盘配置入口，可切换托盘启用状态和启动时隐藏桌宠。
  - 角色切换时从桌宠 happy 立绘生成 32px 托盘缩略图，避免使用 Agent 图标；托盘状态 tooltip 继续保持节流更新。
  - 隐藏桌宠使用原生窗口隐藏，不结束 `ShowDialog()`，托盘图标和 monitor 持续保留。
  - 增强托盘初始化、图标加载、退出清理和异常日志。
- **打包与验证**：
  - 发布包排除 runtime 日志、PID、临时文件和缓存快照。

## 📝 v1.3.0 更新日志
- **Windows 原生任务栏系统托盘（NotifyIcon）常驻支持**：
  - **零伴生进程轻量架构**：主进程内建原生通知区域图标，不新增额外进程，保持极简资源开销。
  - **双击快捷唤醒**：双击托盘图标即时显示、置顶桌宠并触发元气轻跳动效；支持一键将桌宠临时隐藏至托盘。
  - **精简核心托盘菜单**：直观整合工作状态、Codex 额度、专属台词、隐藏气泡、播报暂停（10m/30m/恢复）、角色切换、屏幕边缘位置重置与完整菜单快捷入口。
  - **实时状态 Tooltip**：托盘悬停浮现当前角色与三路 Agent 最新动态（Antigravity、Codex、DSH 任务摘要），3 秒防抖节流更新。
  - **沉浸防打扰逻辑**：“隐藏气泡”后普通状态刷新保持静默，出现 waiting/approval 权限请求时仍智能唤起强制提醒。
  - **托盘生命周期安全管控**：退出时完整释放 NotifyIcon 与菜单句柄，沿用严格的 monitor 进程树、PID 与 Mutex 清理机制。

## 📝 v1.2.0 更新日志
- **三路 Agent 审批与权限感知（WO-12 ~ WO-17）**：
  - **Antigravity 权限审批感知**：精准跟踪 in-flight 非终态任务，动态识别 Transcript 停滞与审批弹窗挂起，解除静态缓存封冻。
  - **Codex 审批与工具停滞检测**：基于 `closedCallIds` 实时配对 `custom_tool_call`，未决工具调用即时触发等待感知。
  - **DSH 交互停滞分析**：毫秒级跟踪 pendingCalls，动态对比停滞阈值，多任务取最新启动时间防误报。
- **桌宠审批提醒与视觉强化**：
  - 醒目琥珀金（`#FFFF9800`）3.4px 加粗气泡边框，离开等待态自动平滑恢复为标准 2.8px。
  - 等待确认态触发「双音清脆提示音（Double Chime）」，并伴随轻快雀跃动画。
  - 60 秒定期轻提醒与 300 秒（5 分钟）自动降级 TTL 机制，兼顾提醒有效性与防打扰。
- **灵活播报控制与状态管理**：
  - 右键菜单新增「状态播报」子菜单，支持快速暂停 10 分钟、30 分钟或立即恢复播报。
  - `config.json` 原生支持 `StallDetectSeconds`（停滞检测阈值，默认 45 秒）与 `PauseMonitorUntil` 配置持久化。

## 📝 v1.1.1 更新日志
- **三路 Agent 全量多会话感知**：
  - **Codex**：全量 JSONL 会话扫描 + 热路径提速至 0.5ms，精准捕获多会话并输出 `sessionCount` 与会话详细列表。
  - **Antigravity**：支持近期 SQLite 数据库与 Transcript 遍历，连接在 `finally` 中严格安全释放，数据库异常 60s 节流并稳定回退至 Transcript。
  - **DeepSeek Harness (DSH)**：支持多会话并发状态与交互检测（问题待答、工具挂起、未结轮次）。
- **多会话界面提示强化**：
  - 主状态气泡任务前新增 `×N` 会话倍数标识（当当前主 Agent 存在多会话并行时显式标出）。
  - 来源徽标悬停 Tooltip 动态展示 Antigravity、Codex、DSH 各自的并行会话数量。
- **状态稳定性与选优优化**：
  - `selectBest()` 优化同级平手优先级算法，防止旧会话挤占新会话。
  - 细化 180s 活动窗口预过滤，大幅削减高频磁盘与文件解析开销。

## 📝 v1.1 更新日志
- **多 Agent 状态实时感知**：协同监测 Antigravity（反重力）、Codex、DeepSeek Harness 等 Agent 的工作、思考、工具调用与空闲状态。
- **Codex 额度实时看板**：支持实时与本地快照双通道读取 5h / 周额度及精确重置倒计时。
- **气泡缩放防裁切优化**：气泡缩放区间收敛为 `[0.8, 1.3]`，水平与垂直边界动态留白，多朝向无裁切。
- **进程生命周期看门狗**：严格验证父子进程 PID 与路径，无父进程安全拦截，杜绝孤儿后台驻留。
- **编码与换行格式净化**：修复换行与 BOM 异常，消除双重空行。

## 🌟 特性与亮点
- **三位元气桌宠立绘**：小克（Claude娘 · 橘白礼服）、龙娘（GPT娘 · 原版）、双子（Gemini娘 · 元气）。
- **Agent 工作状态联动**：实时感知反重力、Codex、DSH 等 Agent 的思考、敲代码、调用工具及等待指令等状态。
- **Codex 额度实时面板**：精准读取 5 小时与每周额度使用百分比及重置倒计时。
- **精致紧凑漫画气泡**：无缝悬浮于角色头顶，标准比例不挡屏、不遮挡窗口。
- **免安装便携**：基于 Windows PowerShell + WPF 原生开发，无须额外环境，双击即用。

## 🚀 启动与使用
- **直接运行**：双击运行 `启动 AgentPet.bat`。
- **创建快捷方式**：双击 `创建桌面快捷方式.bat`，一键生成桌面图标。
- **退出程序**：右键桌宠点击「退出」，或双击 `退出 AgentPet.bat`。
- **开机自启**：双击 `开机自启设置 (可选).bat` 自由开启或关闭。
