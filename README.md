# 🐾 AgentPet

把 Agent 的工作状态带到桌面上，让等待 Agent 工作的时间少一些无聊。

AgentPet 是一款 Windows 桌宠，支持联动 **Antigravity（反重力）、Codex 和 DeepSeek Harness（DSH）**。它会通过气泡展示思考、工作和等待确认等状态，也能帮你查看 Codex 额度与 DeepSeek 余额。

点击桌宠可以查看看板，点击气泡可在额度、余额和随机台词之间切换，还能通过桌宠互动放松一下。

## 🌟 功能介绍

- **Agent 状态联动**：展示三个 Agent 的思考、工作和等待确认等状态。
- **气泡三看板**：切换 Codex 额度、DeepSeek 余额和随机台词，也可以设置默认看板。
- **DeepSeek 余额提醒**：展示人民币余额及可用的充值、赠金明细，低于设定阈值时轻提醒。
- **隐私与数据处理**：工作状态与 Codex 额度从本地读取；DeepSeek 余额由本机 DSH 宿主负责鉴权与查询，AgentPet 不读取或保管登录凭据。
- **免安装便携**：解压后即可启动，无需安装桌宠程序。Agent 状态监控需要 Node.js，DeepSeek 余额功能需要本机 DSH。
- **系统托盘**：显示或隐藏桌宠，切换角色和气泡面板。
- **屏幕边界保护**：按角色可见区域计算拖动边界，气泡不影响位置限制。

## 🚀 下载与使用

前往 [v1.5.1 发布页面](https://github.com/uoweme325/AgentPet/releases/tag/v1.5.1) 下载：

- **日常使用**：`AgentPet_v1.5.1.zip`
- **源码与测试**：`AgentPet-v1.5.1-GitHub.zip`

解压后双击 **`启动 AgentPet.bat`**。需要桌面快捷方式时，运行 **`创建桌面快捷方式.bat`**。

从旧版升级时，请先退出桌宠，备份原目录和个人配置，再解压新版文件进行覆盖。

### 使用前提

- 桌宠运行于 Windows，基于 PowerShell 和 WPF。
- Agent 工作状态监控需要可用的 **Node.js** 运行时。
- DeepSeek 余额功能需要本机运行 **DeepSeek Harness（DSH）**，并在 DSH 中完成账户或服务商配置。

## 📝 v1.5.1 更新日志

### 状态机与推断修复

- **工具执行完毕平滑推进**：工具输出后平滑过渡至下一步思考中（`thinking`），解决工具调用完成后 8 秒回落为空闲的问题；统一缓存状态与重解析状态的推断路径。
- **提问与交互等待感知**：支持 Codex 提问工具（`request_user_input`、`ask_question` 及 `functions.` 前缀剥离）与 Antigravity 提问工具（`ask_question`、`ask_user`），未闭合时识别为等待用户输入（`waiting`），并杜绝已闭合/已答复提问误触等待。
- **在飞与冷启动窗口拓展**：统一在飞与等待态的扫描候选窗口与状态保持窗口（放宽至 300 秒），防止冷启动或重解析时截断长任务与等待态。
- **多会话仲裁机制**：完善 Antigravity 跨会话与同会话仲裁逻辑，同会话遵循完成态优先与步骤容差，跨会话优先保留活跃会话，避免已完成旧会话压制正在进行中的其他会话。

### 余额启动防误报

- **启动基线与未就绪兜底**：启动初期不再直接展示上次遗留的旧快照，建立启动时间戳基线并静默触发刷新；若超过 15 秒未获取到新余额数据，平滑展示「暂不可用」并支持重试，彻底杜绝冷启动误报旧金额或错误触发低额预警。

### 安全退出与防抖重试

- **文件写入防抖重试**：为状态、额度与余额写入增加原子写入失败重试机制（初次失败后最多额外重试 2 次），并降噪重试期间的临时日志。
- **进程优雅关闭与退出校验**：`stop-agent.ps1` 退出脚本先通过投递退出信号与 `WM_CLOSE` 触发桌宠优雅退出并等待 400ms，超时未退出执行强杀兜底，输出精准的四态退出报告。
- **退出标记时效保护**：桌宠启动自动清理残留 `stop.flag`，定时器增加启动时间戳基线与 60 秒时效验证，彻底杜绝残留退出信号引起下次启动闪退。

### 测试套件升级

- 新增状态机与退出链路 13 大综合回归测试（`test/state-machine.test.mjs`，覆盖 13a~13f 全链路）。
- `test/run-all.mjs` 统一测试入口，`test/exit-code.test.mjs` 注入脚本改用临时目录隔离，支持只读环境。

## ⚠️ 使用说明

- 余额看板目前仅支持人民币（CNY）。余额和额度数据仅供参考，请以官方页面为准。
- 同一服务商下的账户切换识别受 DSH 宿主提供的上下文信息限制。
- 多显示器物理热插拔与混合 DPI 场景尚需更多实机验证。若角色移出屏幕，可使用菜单中的位置复位功能。
