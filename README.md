# AgentPet v1.5.0 · 智能桌宠助手

多 Agent 智能协同桌面宠物挂件，支持 **Antigravity**（反重力）、**Codex** 与 **DeepSeek Harness**（DSH）工作状态联动、Codex 额度实时监控与 **DeepSeek 官方 API 账户余额**看板。

> [!NOTE]
> **本地与网络说明**：Agent 工作状态与 Codex 额度均为本地离线读取，不经由任何第三方服务器；启用 DeepSeek 余额功能时，通过本地回环（127.0.0.1）连接 DSH 宿主服务查询余额，AgentPet 不读取也不保管任何 API Key 或登录凭据。

## 📝 v1.5.0 更新日志
- **DeepSeek 官方余额看板与低额预警**：
  - **官方 API 余额查询**：支持接入 DeepSeek 官方 API 账户余额（`GET https://api.deepseek.com/user/balance`）。
  - **DSH 宿主桥接方案**：采用 PC2005-cloud/dsh-pet 宿主方案，由 DSH 宿主统一负责鉴权与查询，AgentPet 通过本地回环接收归一化余额结果，桌宠本身不要求、不读取也不保管任何 API Key 或登录凭据。
  - **独立调度、统一预算与保守降级**：连接 DSH 宿主后默认每 5 分钟同步一次，网络异常按 1/2/5/10/15 分钟退避重试；使用独立 `refresh-balance.flag` 支持手动即时刷新；全链路采用统一截止时间预算机制（单次查询后端总预算上限严格控制在 10 秒，涵盖端口探测、POST 刷新与 GET 状态共享剩余预算），前端设置 10 秒冷却与 15 秒超时保护（留足 5 秒调度余量）。若发生超时、网络故障或凭据缺失，执行保守安全降级，立即清空历史金额缓存，绝不沿用历史金额展示或误触发旧账户低额预警，杜绝无限挂起。
  - **币种与可用性展示**：按币种分别呈现总余额、充值余额与赠送赠金额，不混合相加；显式标识 `is_available` 账户可用状态；提供官方计费定价页直达链接。
  - **低额柔性提醒**：当前版本仅按人民币（CNY）余额判断低额提醒，阈值 LowBalanceCnyThreshold（默认 5.00，可在菜单中按需调整或关闭）；USD 账户暂不告警。主动抑制工作与审批通知，不抢占工作状态。
- **气泡默认偏好与运行时翻页**：
  - **长期偏好与临时翻页解耦**：`config.json` 中的 `BubbleMode` 作为默认偏好（支持 `quota` / `deepseek` / `quote`）；点击气泡空白区域可在三种面板间循环翻页，普通翻页不污染修改配置文件。
  - **本体交互分流**：空闲时点击本体唤起默认看板；工作中点击本体可临时查看默认看板 8 秒，结束后自动恢复工作状态；审批/等待确认具备即时最高优先级。
  - **刷新按钮事件隔离**：点击气泡内刷新按钮精确标记处理完毕，杜绝误触发气泡翻页。
  - **托盘与右键菜单直达**：提供右键与托盘「气泡默认偏好」单选切换，并支持「查看并刷新 DeepSeek 余额」一键直达。
- **角色拖动边界与多屏算法统一重构**：
  - **统一 Alpha 可见包围盒**：基于各角色立绘 Alpha 像素边界（Claude 357×367、Dragon 382×375、Gemini 376×306）、Viewbox 缩放、Canvas 偏移与镜像朝向，精确计算物理屏幕坐标。
  - **突破顶边受限缺陷**：彻底剔除 `Update-Scale` 对整个 390×390 透明窗口顶部的机械硬性夹紧，统一落实“角色本体最多移出屏幕一半”规则，实测各种缩放比例与朝向下角色均可自如移至屏幕顶边。
  - **中心多屏与混合 DPI 适配**：由角色本体视觉中心取代原全窗口几何中心选取目标屏幕，支持按显示器工作区处理负坐标与不同排列；混合 DPI 和物理拔插场景尚需更多实机验证。

## 🌟 特性与亮点
- **三位桌宠立绘**：小克 (Claude娘)、白龙 (GPT娘)、双子 (Gemini娘)。
- **Agent 工作状态联动**：实时感知反重力、Codex、DSH 等 Agent 的思考、敲代码、调用工具及等待指令等状态。
- **双看板额度监控**：原生支持 Codex 剩余使用额度看板与 DeepSeek 官方 API 账户余额监控。
- **精致紧凑漫画气泡**：无缝悬浮于角色头顶，标准比例不挡屏、不遮挡工作窗口。
- **免安装便携**：基于 Windows PowerShell + WPF 原生开发，无须额外环境，双击即用。

## 🚀 启动与使用
- **直接运行**：双击运行 `启动 AgentPet.bat`。
- **创建快捷方式**：双击 `创建桌面快捷方式.bat`，一键生成桌面图标。
- **退出程序**：右键桌宠点击「退出」，或双击 `退出 AgentPet.bat`。
- **开机自启**：双击 `开机自启设置 (可选).bat` 自由开启或关闭。
- **查看 DeepSeek 余额**：启动 DeepSeek Harness 后桌宠自动通过本地回环桥接同步余额，无需配置任何环境变量。
