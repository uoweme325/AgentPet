AgentPet v1.5.0 · 智能桌宠使用说明

1. 启动程序：
   直接双击运行「启动 AgentPet.bat」即可唤起。

2. 桌面快捷方式：
   双击「创建桌面快捷方式.bat」可在桌面生成 AgentPet 快捷方式。

3. 退出程序：
   右键桌宠点击「退出」，或双击「退出 AgentPet.bat」。

4. 核心功能：
   - 自动联动反重力 (Antigravity)、Codex、DSH 等 Agent 的工作状态。
   - 实时查看 Codex 额度与 DeepSeek 官方 API 账户余额。
   - 气泡空白处点击可在 Codex 额度、DeepSeek 余额与闲聊台词间轮播。
   - 右键自由切换角色（小克、龙娘、双子）、缩放比例与气泡默认偏好。
   - 联动 DeepSeek Harness (DSH) 宿主查询余额，无需配置环境变量。
